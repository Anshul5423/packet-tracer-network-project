Enterprise network design and simulation project using Cisco Packet Tracer with LAN, WAN, VLAN, routing, and switching configurations.

# Network Design Project

## Overview
This project contains a Cisco Packet Tracer simulation for an SME network design.

- LAN and WAN configuration
- Router and switch setup
- VLAN implementation
- DHCP and static routing
- Network security basics
